# FlowShelter

FlowShelter is a simple application designed to help people plan their spending
between paydays while reaching their goals. It brings together a web experience, a mobile app, and a backend API around one simple idea: make the days between paydays easier to manage.

## Technology stack

- **Web:** React, TypeScript, and Vite
- **Mobile:** Python and Flet
- **Backend:** Python and FastAPI
- **Database:** PostgreSQL

## Project structure

- `web/` — browser-based application
- `mobile/` — Flet app
- `backend/` — FastAPI service
